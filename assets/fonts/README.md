# Fonts

`DMSans-Bold.ttf` is a static Bold instance (wght 700, opsz 14) generated from the DM Sans variable font. It is used only by `src/app/opengraph-image.tsx`, because the OG renderer cannot read woff2. The site itself loads DM Sans through `next/font`. Licensed under the SIL OFL 1.1 (see `OFL.txt`).
